LCD 通过 SPI 驱动。



| 信号名 | 作用 | 对应你原理图里的网络名 |
| ------ | ---- | ---------------------- |
|        |      |                        |

| SCLK / CLK | SPI 时钟线，MCU 输出时钟 | `SPI1-SCL` |
| ---------- | ------------------------ | ---------- |
|            |                          |            |

| MOSI / SDA / DIN | MCU 发数据给 LCD | `SPI1-MOSI` |
| ---------------- | ---------------- | ----------- |
|                  |                  |             |

| MISO / SDO | LCD 回传数据给 MCU，很多屏不用 | `SPI1-MISO` |
| ---------- | ------------------------------ | ----------- |
|            |                                |             |

| CS   | 片选，选中 LCD | `SPI1-CS` |
| ---- | -------------- | --------- |
|      |                |           |

| D/C  | Data / Command，区分“命令”还是“显示数据” | `LCD-D/C` |
| ---- | ---------------------------------------- | --------- |
|      |                                          |           |

| RESET | 复位 LCD 控制器 | `LCD-RESET` |
| ----- | --------------- | ----------- |
|       |                 |             |

| BL / BG / BCKL | 背光控制 | `LCD-BG` |
| -------------- | -------- | -------- |
|                |          |          |

| 3V3  | 屏供电 | `3V3` |
| ---- | ------ | ----- |
|      |        |       |

| GND  | 地   | `GND` |
| ---- | ---- | ----- |
|      |      |       |

SPI1-SCL     → LCD 的时钟
SPI1-MOSI    → LCD 的数据输入
SPI1-CS      → LCD 片选
LCD-D/C      → 命令/数据选择
LCD-RESET    → LCD 复位
LCD-BG       → LCD 背光
